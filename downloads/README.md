# 開発用プラグインZIP v0.1.5

[v0.1.5 モーション内の切り抜き対応版をダウンロード](https://github.com/blackdog0606-dotcom/kenshiro/raw/refs/heads/main/downloads/kenshiro-blackcrop-mvp-0.1.5.zip)

**「①解析 → ②適用」で、解析値をエフェクトコントロールの「モーション → 切り抜き（左端・上端・右端・下端）」に反映します。** モーションのスケール・位置・回転・アンカーポイントは変更しません。

旧版で追加した標準Cropが1つ残っている場合は、その四辺を0%に戻す操作とモーション内の四辺の設定を同じトランザクションで行い、二重の切り抜きを防ぎます。Cropエフェクト自体は残します。キーフレーム、Zoom、ぼかし、未知の構成などで安全に処理できない場合は、理由を表示してスキップします。モーションに対象の4項目がない場合も変更しません。

検出処理と黒判定・95%判定・0.1%への丸めはv0.1.4から変更していません。セリフや描画が枠に重なる難しい画像の判定修正は含めていません。

- 対象: Premiere Pro 25.6以降。モーション内の切り抜き4項目が必要です。
- 同梱: ビルド済みUXPパネル、ソース、導入手順、生成したテスト用TIF10枚
- 配布形式: UXP Developer Toolで読み込む開発用ZIP。署名済みCCXではありません。
- 検証: 自動テスト189件成功、ZIP CRC検査成功
- ZIPサイズ: 237,385バイト
- SHA-256: `34adc45d47aeabee432ebb5c1b64c29be07c1e69ddf28be58abf1c3931af67b9`

旧版をUXP Developer Toolで **Unload → Remove** し、新しいZIPを解凍して `kenshiro-blackcrop-mvp-0.1.5/manifest.json` を **Add Plugin → Load** してください。

見出しと起動状態がv0.1.5になったら、タイムラインの静止画1枚を選択して **①解析 → ②適用** します。エフェクトコントロールの **モーション内の切り抜き4項目** に、結果欄と同じ数値が表示されることを確認してください。変更は1クリップにつき1回のUndoに登録します。

Premiere Pro 26.5.2の実機診断で対象の名前と数値形式は確認済みです。v0.1.5によるモーション値の書き込みと実画面の反映は、このLinuxクラウドでは実機検証していません。まず1枚で確認してください。ユーザー提供の画像はZIPに含めていません。
