# 開発用プラグインZIP v0.1.6

[v0.1.6 モーション適用修正版をダウンロード](https://github.com/blackdog0606-dotcom/kenshiro/raw/refs/heads/main/downloads/kenshiro-blackcrop-mvp-0.1.6.zip)

v0.1.5で適用時に `The script object is no longer valid` と表示されるケースへの修正です。値を書き込むトランザクション内で対象のネイティブオブジェクトを取り直し、キーフレームと設定アクションを作成します。読み戻しと復元でも古いオブジェクトを使い回しません。

**「①解析 → ②適用」で、解析値をエフェクトコントロールの「モーション → 切り抜き（左端・上端・右端・下端）」に反映します。** モーションのスケール・位置・回転・アンカーポイントは変更しません。

旧版で追加した標準Cropが1つ残っている場合は、その四辺を0%に戻す操作とモーション内の四辺の設定を同じトランザクションで行い、二重の切り抜きを防ぎます。Cropエフェクト自体は残します。キーフレーム、Zoom、ぼかし、未知の構成などで安全に処理できない場合は、理由を表示してスキップします。モーションに対象の4項目がない場合も変更しません。

検出処理と黒判定・95%判定・0.1%への丸めはv0.1.4から変更していません。セリフや描画が枠に重なる難しい画像の判定修正は含めていません。

- 対象: Premiere Pro 25.6以降。モーション内の切り抜き4項目が必要です。
- 同梱: ビルド済みUXPパネル、ソース、導入手順、生成したテスト用TIF10枚
- 配布形式: UXP Developer Toolで読み込む開発用ZIP。署名済みCCXではありません。
- 検証: 自動テスト195件成功、ZIP CRC検査成功
- ZIPサイズ: 242,474バイト
- SHA-256: `402403f0483d3d7264170e740b2fb538273f05cae9095dd8cd760c80c8150e6e`

旧版をUXP Developer Toolで **Unload → Remove** し、新しいZIPを解凍して `kenshiro-blackcrop-mvp-0.1.6/manifest.json` を **Add Plugin → Load** してください。

見出しと起動状態がv0.1.6になったら、タイムラインの静止画1枚を選択して **①解析 → ②適用** します。エフェクトコントロールの **モーション内の切り抜き4項目** に、結果欄と同じ数値が表示されることを確認してください。変更は1クリップにつき1回のUndoに登録します。

Premiere Pro 26.5.2の実機診断で対象の名前と数値形式は確認済みです。v0.1.5では上記エラーで適用に失敗したことが報告されています。v0.1.6の検証はネイティブオブジェクトの失効を模したテストと既存の回帰テストによるもので、実機での書き込み成功と実画面の反映は未確認です。まず1枚で確認してください。失敗時は、処理段階や対象の辺を含む失敗理由と診断情報を確認できます。ユーザー提供の画像はZIPに含めていません。
